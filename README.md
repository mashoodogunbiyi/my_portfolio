# Mashood Ogunbiyi Portfolio

A responsive data engineering portfolio built with semantic HTML, modern CSS, and vanilla JavaScript. The site presents selected projects, technical skills, professional experience, education, contact links, and a public-safe browser CV.

## Run locally

From the repository root, run:

```bash
python3 -m http.server 4173 --directory dist
```

Then open `http://localhost:4173` in a browser.

## Project structure

```text
dist/
├── index.html    Portfolio website
├── cv.html       Public-safe CV with print and PDF support
├── styles.css    Responsive layout and visual design
└── script.js     Navigation, scroll states, copy email, and CV printing
```

## Technology

- HTML5
- CSS3
- Vanilla JavaScript

No framework or build step is required.
